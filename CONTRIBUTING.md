# 🤝 Contributing to N-Zik-Desktop

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [cybruGhost/DESKTOP-CUBIC-MUSIC](https://github.com/cybruGhost/DESKTOP-CUBIC-MUSIC). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/N-Zik-Group/N-Zik-Desktop.git

## ✅ Verify your changes

Initialize the required submodules and follow the desktop build instructions in the README. Include the OS, build result and test steps for the changed feature.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
